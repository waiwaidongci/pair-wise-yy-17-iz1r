# 钟乳石洞穴微环境巡测

巡测登记 + 汛情接力：上游来水一上报，系统按样点警戒线自动建单、归单累加，值班员按名册逐人核销、录入退水复测后销警，不再靠电话追名册和封洞状态。

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 页面分工

- **汛情看板**：未结束汛情单、在洞未核销人数、已封洞样点、上报量一览，可直接处置。
- **汛情接力台**：左侧登记来水点、洞口水位、上涨速率、当班人；右侧未结束汛情单（录入退水复测、销警）；下方上报流水可更正读数。
- **撤离名册**：进洞登记，值班员按名册逐人核销出洞。
- **汛情单档案**：全部汛情单（含已销警）检索留档。
- **巡测记录 / 样点档案**：微环境读数，以及样点警戒线、封洞状态维护。

## 汛情规则

1. 上报洞口水位达到样点警戒线 → 自动建「未结束」汛情单，样点自动封洞。
2. 同一样点已有未结束汛情单 → 重复上报归到原单累加（次数、峰值、最新读数随上报刷新）。
3. 洞内有访客未核销 → 不能直接销警；须由值班员在名册逐人核销。
4. 销警前必须录入退水复测值，且复测值低于警戒线。
5. 上游读数或警戒线更正后，未销警结论自动失效并重判（超警未销 / 回落待销）；退水复测后若复涨达警，复测值失效需重录。
6. 汛情单列表实时显示「还差几人核销」。

## 记录

建单、累加、核销、复测、销警、更正、结论重判都会写入对应记录的 `history`，页面上可回看最近五条。
