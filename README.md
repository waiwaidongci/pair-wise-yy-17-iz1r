# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在 `data/db.json`，后续可以继续增量迭代。

## 汛情接力台（巡测页）

雨季上游涨水期间，巡测页承担"电话之外"的汛情接力：

- **规则层**：`lib/flood.js` 集中判定与流转；HTTP 只在 `server.js` 做参数和存取。
- **记录层**：`floodReports`（水情上报）、`floodEvents`（汛情单，含累加读数、撤离名册、封洞、复测、结论历史）；样点档案的 `floodWarnLevel` 为洞口水位警戒线。
- **页面层**：「汛情接力台」页登记来水点、洞口水位、上涨速率、当班人；「样点档案」页可更正警戒线。

流转规则：

1. 上报洞口水位达到样点警戒线 → 自动建立"未结束"汛情单；同一来水点后续上报（含退水读数）归原单累加。
2. 未达警戒线且无进行中单 → 留档；读数更正后越过警戒线会补建/归并汛情单。
3. 洞内有访客不能销警：值班员先按撤离名册逐人核销，再录入退水复测值；列表与看板显示"还差几人核销"。
4. 复测水位低于警戒线且名册全部核销才允许销警；封洞状态单独登记留痕。
5. 上游读数或警戒线更正后，未销警汛情单的结论自动失效并重新判定（已销警单只留痕、不翻案）。
